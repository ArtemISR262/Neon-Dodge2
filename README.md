# 🎮 Neon Dodge

## О проекте

**Neon Dodge** — это браузерная аркадная игра, разработанная с использованием HTML, CSS и JavaScript.

Цель игры — управлять игровым персонажем, избегать препятствий и набирать как можно больше очков. Проект предназначен для развлечения и демонстрации возможностей веб-технологий.

## Архитектура

Проект состоит из трёх основных компонентов:

1. **HTML (index.html)** — отвечает за структуру игры, игровые элементы и интерфейс.
2. **CSS (style.css)** — отвечает за дизайн, цвета, неоновые эффекты и расположение элементов.
3. **JavaScript (script.js)** — отвечает за игровую логику, управление персонажем, движение объектов и обработку игровых событий.

Все три компонента взаимодействуют между собой и обеспечивают работу игры в браузере.

## Используемые технологии

- **HTML5** — создание структуры веб-страницы.
- **CSS3** — оформление игрового интерфейса.
- **JavaScript** — программирование игровой логики.
- **Git** — контроль версий.
- **GitHub** — хранение исходного кода проекта.
